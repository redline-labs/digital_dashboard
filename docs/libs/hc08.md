# hc08

## Overview

The Freescale CPU08 (HC08) core: the instruction set, the machine that runs it
against its memory map, devices and interrupts, S-record images, and a small
assembler. Three engines run the same core under one contract: an
interpreter, a block engine that runs from a decode cache, and a JIT that
translates those blocks to AArch64 or x86-64 through asmjit. The JIT is the
default; the other two are what it is checked against.

It is a CPU, not a microcontroller: the on-chip modules of a particular part are
[gz60](gz60.html), and the wiring they share is [emu](emu.html).

## Public headers

| Header | |
| --- | --- |
| `hc08/isa.h` | The opcode tables: operation, addressing mode, length and cycles for every opcode on both pages. |
| `hc08/cpu.h`, `hc08/cpu_state.h` | Executing one instruction, and the programmer-visible state. |
| `hc08/engines.h` | `CpuEngine`, `parse_engine`, and the contract every engine keeps. |
| `hc08/machine.h` | `Machine`: memory, devices, interrupts, time, breakpoints, watches, snapshots. |
| `hc08/memmap.h`, `hc08/periph.h` | The address space, and the base of every device. |
| `hc08/image.h` | S-record parsing and loading. |
| `hc08/assembler.h` | `Hc08Asm`: the few instructions a synthetic routine needs, with forward labels. |

## Using it

Link the CMake target `hc08`. The CPU engine is chosen per `Machine` through
`MachineConfig::engine`; `parse_engine("jit")` reads one from text.

## Behaviour worth knowing

The engines must agree instruction by instruction, flags included. A watch or a
breakpoint makes the machine run the block engine while it is set, so the JIT
never needs to know about them.

The JIT drops a translated block when the code under it is rewritten and
translates it again; a program that writes its own code still runs correctly,
only slower.

A malformed S-record is refused, not read past: a record shorter than its own
address field was a buffer overrun until it was checked.

## Tests

| Target | Proves |
| --- | --- |
| `hc08_test_core` | The instructions, the engines, the machine, image parsing (malformed records included) and the JIT, on hand-assembled programs. |
| `hc08_test_engine_diff_block`, `hc08_test_engine_diff_jit` | Random instruction sequences give identical state on the interpreter and on the other engine after every step (slow). |
| `hc08_test_engine_diff_catches_broken` | The same check against an engine broken on purpose must fail: a checker that cannot fail proves nothing. |
